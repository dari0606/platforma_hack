# Как опубликовать Hakk Academy

## 1. Быстрая ссылка с вашего Mac (уже работает)

```bash
cd ~/hakk-academy && npm run public
```
Во второй вкладке терминала:
```bash
cd ~/hakk-academy && bin/cloudflared tunnel --no-autoupdate --url http://localhost:8080
```
В выводе будет ссылка `https://….trycloudflare.com`. Её можно отправить кому угодно.

- Работает, только пока Mac включён, не спит и обе вкладки открыты.
- После перезапуска ссылка меняется.
- Подходит для показа и тестирования, не для постоянной работы.

## 2. Постоянный сайт 24/7 (Render.com)

Ссылка постоянная: не меняется, работает, когда Mac выключен. База (ученики, прогресс, записи) лежит на отдельном диске и не пропадает при обновлениях.

1. Зарегистрируйтесь на **github.com**.
2. Загрузите проект через **GitHub Desktop**, без терминала:
   - скачайте с desktop.github.com и войдите своим аккаунтом GitHub;
   - **File → Add Local Repository** → выберите папку `hakk-academy`;
   - нажмите **Publish repository**, поставьте галочку **Keep this code private** → **Publish**.
   Код обязательно должен быть приватным: в нём внутренние правила академии.
3. Зарегистрируйтесь на **render.com** и войдите через GitHub (разрешите доступ к репозиторию `hakk-academy`).
4. **New → Blueprint** → выберите репозиторий `hakk-academy`. Render сам прочитает `render.yaml`: Docker-сервис, постоянный диск на 5 ГБ под базу и аудиозаписи, секретный ключ. Нужен тариф Starter, около $7 в месяц: на бесплатном тарифе нет постоянного диска и данные будут пропадать.
5. После первого запуска откройте **Logs**. Там будет строка `password: …` — это пароль для `admin@hakk.kz` и других демо-аккаунтов. Сразу войдите и смените его в Профиле.
6. Ссылка будет вида `https://hakk-academy.onrender.com`. Свой домен, например `learn.hakk.kz`, можно подключить в Settings → Custom Domain.
7. Обновления: после новых изменений в GitHub Desktop нажмите **Push origin** — Render сам пересоберёт сайт за 2–3 минуты. Данные при этом сохраняются.

### Перед запуском для учеников
- Смените пароли: либо в профиле, либо на сервере командой `npm run passwords` (Render → Shell).
- Удалите или деактивируйте демо-учеников в Админ-панели → Пайдаланушылар и добавьте настоящих.
- Для восстановления пароля по SMS/email нужно подключить отправку. Точка интеграции — `server/routes/auth.js` (`/forgot`).
- Делайте резервные копии диска: Render → Disks → Snapshots.
