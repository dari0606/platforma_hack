# Как опубликовать Hakk Academy

## Как это работает сейчас (Vercel, без базы и без входа)

Сайт работает **без сервера, без базы данных и без регистрации**. Все материалы (уроки, 37 сур
с переводом и аудио, таджвид, әліпби, словарь, тесты) лежат прямо в сайте, в папке `client/public/data`.
Посетитель открывает ссылку и сразу попадает на платформу. Прогресс, закладки и отметки о заучивании
сохраняются в браузере посетителя.

**Публикация и обновление:** просто `git push` — Vercel пересоберёт сайт сам. Ничего настраивать не нужно.

**Если изменили материалы** (через админку на своём компьютере или в файлах `server/seed-data`):
```bash
cd ~/hakk-academy && npm run export:static && git add -A && git commit -m "Обновил материалы" && git push
```
Команда заново выгружает содержимое в JSON, после чего Vercel публикует обновление.

**Чего нет в этом режиме** (для этого нужен сервер с базой, см. ниже):
запись голоса ученика и проверка учителем, личные кабинеты и роли, админка, уведомления,
общий прогресс учеников и аналитика.

## Вариант 2. Постоянный сайт на Render (альтернатива Vercel)

Сайт работает круглосуточно, даже когда ваш компьютер выключен. Ссылка постоянная и не меняется.
Карта не нужна: Neon (база данных) и Render (сам сайт) имеют бесплатные тарифы.

От вас — три входа через кнопку «Sign in with GitHub», примерно 10 минут. Всё остальное уже настроено в проекте.

Код уже загружен в GitHub: https://github.com/dari0606/platforma_hack

### Шаг 2. Neon — база данных (ученики, прогресс, записи)
1. Зайдите на **neon.com** → **Sign up** → войдите через GitHub.
2. Создайте проект: имя `hakk-academy`, регион выберите ближе к ученикам (например Europe/Frankfurt).
3. Скопируйте строку подключения (**Connection string**, начинается с `postgresql://`). Она понадобится на следующем шаге.

### Шаг 3. Render — сам сайт
1. Зайдите на **render.com** → войдите через GitHub, разрешите доступ к репозиторию `hakk-academy`.
2. **New → Blueprint** → выберите `hakk-academy`. Render прочитает файл `render.yaml`.
3. Он спросит значение **DATABASE_URL** — вставьте строку подключения из Neon. Нажмите **Apply**.
4. Через 3–5 минут сайт соберётся. Откройте **Logs** и найдите строку `password: …` — это пароль для `admin@hakk.kz`. Сразу войдите на сайт и смените его в Профиле.
5. Ссылка будет вида `https://hakk-academy.onrender.com`.

### Шаг 4. Свой домен и лендинг (по желанию)
- В Render: **Settings → Custom Domain** → добавьте, например, `oqu.ваш-домен`.
- Render покажет CNAME-запись; добавьте её у регистратора домена (или там, где управляете DNS).
- Лендинг на Tilda оставьте на главном домене, а кнопку «Кіру» ведите на `oqu.ваш-домен`.

### Шаг 5. Чтобы сайт не «засыпал»
На бесплатном тарифе Render усыпляет сайт после 15 минут без посетителей, и первый заход занимает около минуты.
В проекте есть готовый файл автопинга: `deploy/keep-awake.yml`. Включите его так:
1. GitHub → ваш репозиторий → вкладка **Actions** → **New workflow** → **set up a workflow yourself**.
2. Вставьте содержимое файла `deploy/keep-awake.yml` и сохраните (**Commit changes**).
3. **Settings → Secrets and variables → Actions → Variables → New variable**: имя `SITE_URL`, значение — адрес сайта (например `https://hakk-academy.onrender.com`).

(Файл лежит не в `.github/workflows`, потому что для загрузки туда с компьютера нужен токен GitHub с правом `workflow`.)

### Перед запуском для учеников
- Смените пароли: в Профиле или командой `npm run passwords` (Render → Shell).
- Удалите демо-учеников в Админ-панели → Пайдаланушылар и добавьте настоящих.
- Проверьте демо-материалы: тексты уроков и тафсира должны пройти Review → Approved → Published.
- Резервные копии базы: Neon → Backups (на бесплатном тарифе доступна история за 7 дней).

### Сколько это выдержит
Бесплатные тарифы рассчитаны на десятки одновременных учеников. Когда станет тесно:
Render Starter (~$7/мес) убирает «засыпание», Neon Launch (~$19/мес) даёт больше места и копий.
Код менять не нужно — только тариф.

## Вариант 2. Быстрая ссылка с вашего Mac (для показа)

```bash
cd ~/hakk-academy && npm run public
```
Во второй вкладке терминала:
```bash
cd ~/hakk-academy && bin/cloudflared tunnel --no-autoupdate --url http://localhost:8080
```
Ссылка вида `https://….trycloudflare.com` работает, только пока Mac включён и обе вкладки открыты,
а после перезапуска меняется. Для учеников не подходит, для быстрой демонстрации — да.

## Как всё устроено

- Локально (на вашем Mac) данные лежат в файле `data/hakk.db` (SQLite) — ничего настраивать не нужно.
- На сервере, если задана переменная `DATABASE_URL`, тот же код работает с Postgres.
- Аудиозаписи учеников и загруженные файлы хранятся в самой базе, поэтому переживают перезапуски сайта.
