# Hakk Academy — образовательная платформа

**Құран және араб тілі оқу орталығы** · закрытая LMS для учеников, учителей, кураторов и администраторов.

Принцип: **Білім → Түсіну → Практика → Тексеру → Прогресс**.

## Запуск

Требуется Node.js ≥ 22.13 (используется встроенный `node:sqlite`).

```bash
npm install
npm run dev          # API :3001 + Vite :5173 → http://localhost:5173
```

Продакшн:

```bash
npm run build        # собирает фронтенд в dist/
JWT_SECRET=... PORT=8080 npm start   # один процесс: API + статика
```

При первом запуске пустая БД автоматически заполняется демо-контентом. Пересоздать: `npm run seed`.

## Архитектура

```
server/            Express 5 + SQLite (WAL), вся учебная логика на бэкенде
  schema.sql       схема БД (29 таблиц + FTS5-индекс поиска)
  auth.js          bcrypt, JWT в httpOnly-cookie, роли → права
  services.js      прогресс, блокировка уроков, расписание, проверка ответов,
                   поиск, ежедневное повторение, workflow контента, напоминания
  resources.js     описание CMS-сущностей (поля, типы, права). Админка строит
                   формы по этим метаданным: новое поле = одна строка здесь
  routes/auth.js   вход, выход, восстановление пароля, профиль
  routes/app.js    API ученика (дашборд, курсы, уроки, тафсир, тесты, …)
  routes/admin.js  CMS, аналитика, группы, доступы, инструменты учителя
  seed.js          демо-контент
client/src/        React 19 + React Router, mobile-first CSS
  pages/           кабинет ученика
  admin/           админ-панель и генератор форм CMS
  i18n.js          интерфейс на казахском; русский добавляется словарём
```

**Роли и права** (`server/auth.js`):

| Право | Учитель | Куратор | Админ |
|---|:-:|:-:|:-:|
| Создавать/редактировать контент | ✓ | | ✓ |
| Одобрять религиозный контент (Approved) | ✓ | | ✓ |
| Публиковать (Published) | | | ✓ |
| Проверять записи и ДЗ | ✓ | | ✓ |
| Отвечать на вопросы | ✓ | ✓ | ✓ |
| Управлять учениками и группами, выдавать доступы | | ✓ (только ученики) | ✓ |
| Рассылать уведомления | | ✓ | ✓ |

Проверки прав выполняются на сервере. Интерфейс только скрывает недоступные кнопки.

## Достоверность религиозного контента

- Уроки, тафсиры (суры и аяты) и статьи базы знаний проходят workflow **Draft → Review → Approved → Published**.
- **Approved** ставит только учитель или администратор, и только при заполненном источнике (Дереккөз / Ғалым / Кітап). **Published** ставит только администратор и только для одобренного материала.
- Изменение опубликованного материала автоматически возвращает его в **Review**.
- Бейдж «✓ Hakk Academy тексерген» показывается только для опубликованных материалов с отметкой проверки.
- **Демо-данные:** арабский текст сур 89–114 взят дословно из Tanzil (Uthmani, tanzil.net). Переводы аятов, тафсир и выводы **не сгенерированы**: эти поля пустые и ждут преподавателей. Объяснения правил таджвида в демо-уроках написаны как черновой пример. Все демо-материалы помечены `is_demo` и показываются с плашкой «Демо-мазмұн · ұстаз тексеруін күтуде». До запуска их должен проверить ответственный преподаватель.
- Видео тафсиров — реальные ролики с канала youtube.com/@Hakk_academy.

## Как добавить урок без программиста

Админ-панель → **Контент (CMS)** → курс → «+ Сабақ». Заполните цель, вставьте ссылку YouTube (любой формат: watch, youtu.be, shorts, live), конспект и источник. Вкладка «Практика» — упражнения (запись голоса, выбор ответа, сопоставление, пропуски, текст, файл), «Тест» — вопросы 7 типов с объяснением «Неге?». Дальше: «Тексеруге жіберу» → учитель «Бекіту» → админ «Жариялау».

## Масштабирование и следующие шаги

- **БД:** SQL переносим; для тысяч одновременных пользователей нужно заменить `server/db.js` на PostgreSQL (`pg`), а FTS5 — на `tsvector`. Остальной код работает через `all/get/run/insert`.
- **Файлы:** `data/uploads` → S3-совместимое хранилище (единая точка — `server/uploads.js`).
- **Почта/SMS для сброса пароля:** точка интеграции — `routes/auth.js` (`/forgot`), сейчас ссылка пишется в лог.
- **Уже заложено:** словарь, ежедневное повторение, «Менің қателерім», сертификаты, аналитика, центр уведомлений, API-first бэкенд для будущего мобильного приложения.
- **AI-поиск и рекомендации:** расширяются через `search()` и `recommendation()` в `services.js`. Ответы должны строиться только по опубликованным материалам Hakk Academy.
- **Аудиопроверка чтения:** записи хранятся в `submissions`, ошибки — в `mistakes` по тегам правил, их можно передавать в модель распознавания.
- **Русский язык:** добавить строки в словарь `ru` в `client/src/i18n.js`; переводы контента — через колонки `*_ru` или таблицу переводов.
